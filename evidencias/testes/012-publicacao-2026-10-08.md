## Recuperação de senha pelo Gmail real (RF07)

Conta remetente: `orcamarcenaria.sistema@gmail.com` (criada só para o sistema), com senha de app, SMTP `smtp.gmail.com:465`. A senha de app foi colocada no `.env` da VPS pela própria autora; não passou pelo chat nem pelo repositório.

| Passo | Resultado |
|---|---|
| Primeiro teste, sem `SMTP_*` no `.env` | Log: `[e-mail não enviado: SMTP não configurado]` com o link escrito no console. Causa: o roteiro listava as variáveis, mas elas não tinham sido copiadas para o `.env` |
| Variáveis `SMTP_*` e `EMAIL_REMETENTE` acrescentadas e API reiniciada | Nomes conferidos por SSH, senha com 16 caracteres, serviço ativo |
| Novo pedido pelo site ("Esqueceu sua senha?") | E-mail recebido pela autora; a senha foi trocada pelo link. Nenhuma linha de erro de envio no log da API |
| Registro no banco | 2 pedidos de redefinição, os 2 com `usada_em` preenchido (uso único); o banco guarda só o hash do token |

## Limites desta evidência

- A abertura do link já usado ("link inválido ou expirado") e o encerramento das sessões estão cobertos pelos testes de integração, não foram reexecutados no site publicado.
- O orçamento CT03 (R$ 2.760,00) **não foi conferido no endereço publicado** nesta sessão.
- A base publicada tem 1 usuário, 1 cliente, 1 orçamento e 2 materiais. A revisão de que são só dados fictícios (RNF15) cabe à autora antes de enviar o link ao orientador.
- Testado só com Gmail como destino; não se mediu entrega em outros provedores nem o tempo de chegada.
