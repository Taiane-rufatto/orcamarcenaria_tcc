# Validação manual

1. Execute `npm run migrar` no backend e inicie backend e frontend.
2. Entre com uma conta fictícia.
3. Cadastre material com custo `1,2350` e serviço por hora.
4. Busque, edite e inative os dois registros.
5. Reative um item inativo com o botão "Reativar" e confirme que ele volta à lista de ativos.
6. Confirme que a listagem padrão mostra somente ativos e outra conta não vê os registros.
